# 积分发行库存

入口：独立后台 → 钱包管理 → 积分发行与发放。仅总管理员可操作，写入要求近期邮箱验证。

1. 新增积分：填写数量与原因，核对后将积分记入平台库存，不增加任何用户余额。
2. 发放给用户：查找并确认用户名、显示名称，输入数量与原因。服务器从库存扣除相同数量，记入该用户的普通积分（purchased）。库存不足、停用用户、冻结钱包都会拒绝发放。
3. 后台显示库存、累计新增、累计发放和分页记录。每笔保留操作人、接收人、原因、时间和账本编号。请求断网后保留原请求编号，重试与刷新不会重复发行或发放。

新增不是 USDT 链上充值。发行库存以 inventory/ reserve 平衡分录记录；发放以 inventory/用户 purchased 平衡分录记录。不会修改历史余额或补记虚构的链上收款。发放积分沿用现有打赏、C2C、提现规则，不直接成为可提现的打赏收入。新增库存不计入任何用户的财富头衔；发放后计入接收用户持有积分，不增加打赏等级。

旧的正向余额调整接口同样从库存发放，不能绕过库存发行；收入积分不能通过该接口直接新增。余额扣减仍保留为独立的纠错功能，不返还库存，不覆盖历史流水。已完成的历史请求仍可幂等核对。

初始库存为零。本次迁移不发行、不发放真实积分。库存上限为 1,000,000,000,000 积分；单次新增/发放上限为 1,000,000,000 积分，最小精度 0.0001。金额使用整型账本单位计算，服务器行锁防止并发超发。

保留旧 merchant issuance 账户与历史，商家申请、保证金、交易担保额度均不改变。
