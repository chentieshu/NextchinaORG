# 社区界面与账号架构

更新：2026-10-13。正式地址：https://chinateam.org 。

## 信息架构

移除顶部导航、首页大标题和导语。全站使用同一个左侧栏：论坛首页、统一搜索、新闻、收藏、个人主页、设置、管理员入口及发帖按钮。手机保留带可访问名称的图标侧栏。首页只有帖子流、全部/关注切换、排序和当前分类提示；正文右侧展示素材。分类继续来自后台维护的 `omni_categories`。

## 账号与登录

1. Google、GitHub、X、邮箱链接或密码验证身份，仍由 Supabase Auth 处理。
2. 新账号第一次验证成功后设置名称和唯一用户名。名称允许重复，用户名大小写统一为小写，限制为 3–40 位字母、数字、下划线。保留项目已有长度规则，避免破坏历史用户名；不照搬 X 的长度限制。
3. 数据库确认完成后才开放发帖、评论、点赞、收藏和关注。`profile_completed_at` 由受控 RPC 设置，客户端不能直接修改，第三方 metadata 不能跳过此步骤。失败或用户名冲突保留输入。
4. 已明确选择过用户名的旧账号无需重复设置。自动生成的占位用户名需要确认。已有内容、角色及关注关系继续使用 UUID 关联，修改用户名不会更换身份。

名称、头像与唯一用户名在列表中统一显示。第三方头像完成资料后复制到 Cloudflare R2；沿用头像裁剪、上传和手动恢复，不增加第二套用户表或存储。

OAuth 回调只接受本站五语言路径，拒绝外站跳转。账号恢复和绑定优先回到账户安全设置。邮件在其他浏览器打开时可能没有原浏览器的返回路径，默认进入首页。用户名用于公开身份与搜索；目前仍通过邮箱或提供商登录，不提供用户名密码登录。

## 三种语言概念

| 范围 | 行为 |
|---|---|
| 界面 | 五语言字典，选择入口仅在设置；已登录账号保存 `ui_locale`，登录时应用，访客在当前浏览器保存 |
| 帖子 | 只有一份作者原文，无翻译编辑器、语言筛选或自动翻译；切换界面不会改变内容 |
| 新闻文章 | 管理员维护同一文章的五语言版本；显示当前界面对应译文，缺少时展示原文及提示 |

保留现有内容表和富文本格式。帖子使用 `translations[original_locale]` 作为兼容存储键，它不是内容语言检测结果，也不限制作者使用其他语言。数据库限制新帖子/正文更新为单份原文，编辑旧帖子时保存原始键，避免把界面语言写入内容身份。历史多语言字段不批量删除，公共列表与阅读仅取原文；作者下一次编辑时会规范化为单份原文。新闻继续保留多语言字段。

## 偏好与状态

设置中统一管理浅色、深色、跟随系统及界面语言。账号偏好通过有身份检查的 RPC 更新，带 `updated_at` 防止覆盖另一页面的修改。发生冲突可载入最新资料后重新选择。语言跳转由应用外壳统一执行，避免设置页和外壳重复导航。

继续共用现有 Context、会话、内容缓存、编辑器和网络状态。资料更新有版本计数，较早启动的账号刷新不能覆盖刚保存的资料。账号变更清理私有缓存，搜索取消过期请求并校验请求序号，分页和搜索条件由 URL 保存。编辑器保留本地草稿与服务端冲突检查。

其他设备的变化在重新读取资料时生效，尚未实现跨设备实时推送。主题会响应本设备的系统设置和浏览器存储事件；帖子、通知等没有引入 Realtime。详见 [后台与生产缺口](admin-and-operations.md)。

## 搜索边界

公共入口 `/{locale}/search/?q=...&type=...`，快捷键 Ctrl/Cmd+K。一个请求支持帖子、新闻、用户和回复，可以按类型筛选，分页每次 20 条。正文结果沿用帖子/文章卡片，用户进入个人页，回复进入所属讨论。

`omni_search` 在服务端显式限定已发布内容、未删除回复和正常公开用户。即使管理员调用公共搜索，也不返回草稿；管理后台仍使用独立的有权限检查的内容搜索。公开用户结果只有 ID、名称、用户名、头像和简介，不包含邮箱、角色、语言和主题偏好。

目前是大小写不敏感的字面子串查询，支持中文、日文等文本匹配，限制关键词 120 字符和分页大小；并非语义搜索、自动翻译、分词相关性排序或大规模全文检索。随数据增长应评估统一检索文档/索引、PGroonga 或专用搜索服务，再做容量测试。当前排序按创建时间，并发写入时偏移分页不是数据库快照。

## 验证与发布

数据库测试实际执行全部迁移，覆盖不完整账号绕过 UI、大小写用户名冲突、偏好并发保存、帖子单原文约束，以及草稿/下架内容/已删除回复的搜索隔离。浏览器测试覆盖侧栏、五语言窄屏、引导、偏好持久化、搜索分页和过期请求、新闻翻译与帖子原文、回调路径。浏览器中的已登录操作使用拦截测试数据，不向生产发测试帖或邮件。

迁移 `20261013090453_social_shell_onboarding_preferences.sql` 先于前端发布；不更换 Supabase 项目、OAuth 客户端或媒体存储。不完整旧账号会在下一次访问时看到资料设置，这是预期的兼容行为。

## 设计依据

- 2026-10-14：品牌统一为 ChinaTeam。转发是用户与原帖的唯一关联，引用是独立帖子、只展示一层原帖摘要；原帖下架或删除后显示不可用占位。普通成员不能引用或转发私密、未发布内容。
- `omni_content_drafts` 独立保存已发布内容的修改，仅保存者可见。草稿与线上正文均做版本冲突检查，发布和草稿清理在同一事务完成。不同语言新闻独立发布，帖子保持单份原文。已发布内容的引用身份不可修改。
- 界面语言、新闻筛选语言分开；全语言新闻按界面语言选择现有译文，否则明确使用原文。帖子不自动翻译。外部播放器默认点击后加载，可在阅读设置启用自动加载。
- Cloudflare Worker 为 YouTube / Spotify 提供 oEmbed 元数据和代理缩略图，为 GitHub 公开仓库提供元数据与统计。固定上游主机、限制响应体和超时、拒绝任意 URL 抓取，缓存预览并设置独立限流；无法预览时保留原链接。X 使用官方嵌入，可能受原帖可见性及浏览器限制影响。
- 验证器支持设置、验证和移除。对已绑定验证器的账号，数据库权限和 R2 管理监控都要求 `aal2`；未绑定的账号不强制启用。没有自助备用恢复码，丢失验证器须联系站点支持。
- 焦点回归刷新同时更新回复正文与数量；互动继续使用原有共享状态，按账号隔离，重复操作串行，过期请求不能覆盖新状态。未增加另一套状态库，跨设备实时推送仍待后续实现。
