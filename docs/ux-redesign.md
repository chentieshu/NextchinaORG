# 整站 UX 盘点与重设计

基线：`c3fb7d29bffb4ebacbb944b61ea835f9e8b71827`。自动清单见 `ux-baseline.json` 与 `ux-inventory.json`；路由文件数量不等同于独立功能页，包含语言模板、别名和回调入口。

## 页面清单

共 25 个路由文件：前台 19 个，独立后台 6 个。所有语言模板覆盖简体中文、英文、日文、西班牙文和繁体中文。

| 应用 / 路径 | 任务与最终设计 |
| --- | --- |
| 前台 `/`、`/[locale]/` | 同一论坛首页；只保留动态筛选、列表和操作，移除重复搜索及分类辅助栏 |

| 前台 `/about/` | 组织用途、社区规则与联系入口；保留真实说明，无新增装饰内容 |
| 前台 `/privacy/`、`/terms/` | 公开法律与隐私内容；保留完整内容及联系方式，统一阅读排版 |
| 前台 `/auth/callback/` | 登录或恢复回调；保留等待、失败和重试状态 |
| 前台 `/admin/`、`/market/`、`/wallet/predictions/` | 旧路径跳转；维持兼容，不新增重复页面 |

## 后台分区

| 分区 | 信息层级 |
| --- | --- |
| 概览 | 真实计数、状态图表、精确值及筛选跳转；移除重复快照标签 |
| 帖子 / 文章 | 一个标题、搜索、状态筛选及主操作，表格保留管理权限 |
| 评论 | 回复内容与管理操作，无重复介绍 |
| 用户 | 用户信息、角色、账号状态；保留权限限制 |
| 分类 | 列表与新增入口；编辑在聚焦弹窗中完成，取消后恢复触发按钮焦点 |
| 钱包 | 真实余额、库存、身份管理、网关与提现审核；保留账本和操作确认 |
| C2C | 商家、订单和设置，移除与页面标题重复的内部标题 |
| 预测市场 | 市场管理、提案、结果和争议处理；保留证据与确认 |
| 监控 | 采集结果、失效与部分扫描标记；不把未知用量显示为正常 |
| 审计 | 操作记录与分页，无重复解释段落 |
| 全站设置 | 公告、评论与发帖开关及保存；保留并发冲突反馈 |

## 统一规则

- 全视口外框保持，导航从频繁使用的目的地开始；个人主页和收藏放入账户菜单，文章分类只在文章页出现。
- 表单按任务展示，隐藏面板保持挂载，切换不会清空草稿，也不会自动提交或发送邮件。
- 页面只用一个可见主标题。导航图标用于识别操作，删除说明功能本身的重复介绍、快照标签和装饰段落。
- 中性浅深配色、统一圆角、标题字号和间距；语义颜色继续用于异常、成功与交易方向。
- 不删除错误恢复、限制原因、付款地址及网络、费用、二次确认、隐私政策或真实用户内容。
- 数据库、资金规则、权限策略和服务凭据不随视觉调整改变。

## 验证

浏览器测试覆盖导航收拢、五语言响应式、分组设置、未保存输入、历史恢复、分类网址状态、分类弹窗、登录、发帖、头像、串文、回复及既有交易和后台流程；全部请求使用隔离数据。样式检查要求无重复选择器上下文、重复属性或未定义变量。
