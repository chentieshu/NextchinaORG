后续 UX 重设计保留全视口外框，移除重复辅助栏，并将设置改为任务分组。当前设计以 [ux-redesign.md](./ux-redesign.md) 为准，下文保留首次全视口改造记录。

## 改造前统计

基线为 `5409974059103438dc2fc9a95893794f56de4b0e`，包含最新 BTC 图表、预测市场与 1:1 积分兑换实现。

- 前台 19 个路由文件，其中 3 个为跳转入口；覆盖简体中文、英文、日文、西班牙文和繁体中文。
- 全项目 23 个样式文件、2,017 条规则、5,875 条声明；重复选择器上下文、重复属性和未定义变量均为 0。
- 前台外框最多 1,160px；1920px 屏幕两侧合计留空 760px，约占 39.6%。交易模块还单独定义外框上限，宽度归属分散。
- 侧栏整体滚动会裁切账户菜单；页面高度依赖多个 `vh` 下限，短内容页的页脚位置不一致。

## 最终布局

外框宽度为整个视口，主工作区最小高度为动态视口高度，页面保留正常文档滚动。没有新增顶部导航或横幅。

| 视口宽度 | 导航与内容 |
| --- | --- |
| ≤ 900px | 单列内容、固定底部导航、安全区留白；不显示两侧栏 |
| 901–1200px | 204px 左侧导航、自适应内容；分类可从侧栏展开 |
| 1201–1439px | 216–256px 自适应导航与内容 |
| ≥ 1440px | 论坛、文章、用户、收藏和搜索页采用左侧导航 + 主内容 + 280–360px 辅助区 |

辅助区复用 Provider 已加载的真实文章分类及搜索入口，不增加请求或虚构统计。宽屏时隐藏左侧重复的分类入口。搜索快捷键仍打开统一搜索页。

设置、写作、钱包和预测市场使用完整主工作区，隐藏辅助区。设置在 ≥1200px 下为双栏面板；钱包四项余额使用四列，手机为两列。文章和帖子详情保持不超过 880px 的阅读宽度，编辑器保留自身行宽。帖子继续隐藏姓名和用户名，保留头像、徽章与右侧素材。

导航列表独立滚动，账户菜单位于滚动容器之外，短屏仍可操作。页脚随工作区排版；移动导航长标签单行省略，完整名称由无障碍标签保留，避免多语言换行遮挡页脚。

## 样式归属与验证

`public.css` 统一管理前台外框；删除预测市场模块对全局外框的覆盖及未使用的旧侧栏结构。独立后台继续只加载共享基础样式和后台样式。

自动统计见 [ui-audit.json](./ui-audit.json)。验证包括样式重复检查、前后台构建、类型检查，以及隔离数据的浏览器回归；覆盖 320–2560px、480px 短屏、五种语言、浅深主题、侧栏菜单、底部导航、分类跳转、搜索快捷键、设置锚点和阅读行宽。测试不会向生产服务发送邮件或资金写请求。
