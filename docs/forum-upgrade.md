# 论坛与写作

首页为开放的列表论坛，所有正常登录的成员均可发表帖子。顶部导航切换论坛与新闻，桌面侧边栏提供分类、我的帖子、收藏和管理员入口，主区展示搜索、排序、发帖按钮与帖子列表。手机侧边栏收为可展开的筛选菜单。分类、搜索、排序和“我的帖子”同步到 URL，刷新、分享与浏览器返回会保留当前筛选；退出登录后不再显示私人草稿。首页与新闻页均无横幅或轮播。

帖子正文的首张 HTTPS 配图显示在列表右侧，点击标题或配图打开全文；无图或图片加载失败时使用纯文字布局。置顶继续影响列表排序。“共创”指成员共同发帖和讨论，成员只能修改自己的帖子；管理员管理全站帖子与评论。新闻仅子管理员、总管理员可以发布，前端入口与数据库权限共同限制。原有真实内容不变。

## 权限

| 操作 | 游客 | 普通成员 | 子管理员 / 总管理员 |
| --- | --- | --- | --- |
| 阅读公开帖子与新闻 | 可以 | 可以 | 可以 |
| 发表帖子 | 需登录 | 可以 | 可以 |
| 发布新闻 | 不可以 | 不可以 | 可以 |
| 编辑、删除自己的帖子 | 不可以 | 可以；锁定或下架后不能编辑 | 可以 |
| 管理所有帖子、新闻 | 不可以 | 不可以 | 编辑、置顶、锁定、下架、恢复、删除 |
| 评论、点赞、私人收藏 | 需登录 | 可以 | 可以 |
| 编辑、删除评论 | 不可以 | 自己的评论；锁定后不能编辑 | 所有评论 |
| 用户角色、账号停用、全站设置、审计 | 不可以 | 不可以 | 仅总管理员 |

权限由 Supabase RLS、列级授权和触发器执行。作者、内容类型和身份字段不可通过客户端修改。停用账号不能发帖、编辑或互动。成员不能自行撤销管理员的锁定、下架或置顶操作。删除帖子会一并删除关联评论、点赞和收藏，因此界面要求确认。

## 写作流程

1. 首页选择“发表帖子”；管理员可在新闻页或管理中心选择“撰写新闻”。
2. 输入标题和正文。编辑器支持选中文字后格式化，以及标题、粗体、斜体、引用、列表、代码块、链接和图片。
3. 图片通过 HTTPS 地址插入，并可填写说明；当前不提供本地文件上传。阅读页仅渲染允许的格式，外部图片不发送来源页地址。
4. 草稿自动保存在当前浏览器，并按账号和内容隔离。点击“保存草稿”才会保存至服务器，之后可从“我的帖子”或管理中心继续编辑。成员自己的草稿不对其他成员或游客公开。
5. 使用语言选择框编辑五种语言版本；缺少翻译时读者看到原文和提示。已添加的语言版本需填写标题与正文。
6. 点击“预览”检查排版，再发布。原有纯文本新闻可直接进入新编辑器修改。

总管理员可在全站设置中关闭成员发帖或全站评论。普通成员每 30 秒最多新建一篇帖子，评论至少间隔 10 秒。帖子、新闻及收藏每页 20 条，评论和后台每页 50 条。搜索在服务端匹配所有语言的标题与摘要，不受前 500 条限制；列表不传输正文与文档。大规模全文索引、图片上传和预审队列仍需另行实现。

## 状态与恢复

- 登录有加载、成功和失败状态；受保护页面等待账号读取完成。退出或更换账号后清除私人互动状态，旧请求不能覆盖新账号。
- 列表搜索有 300ms 延迟，旧请求会取消；分页、重试与网络错误均有明确反馈。详情刷新不会重建尚在输入的评论。
- 新建及已有文章的本地草稿按账号和内容隔离。700ms 后自动保存；离线可继续写作，但需要恢复网络才能同步到服务器。
- 帖子、新闻及评论编辑携带服务器更新时间，检测到另一处更新时不会覆盖；文章草稿保存在本地，可重新载入后选择恢复或放弃。
- 写作中的链接跳转及关闭页面提示未保存修改。此提示受浏览器限制；浏览器历史返回不一定弹出确认，但组件退出会尽力保存本地草稿。
- API 操作防止重复提交，并核对返回行。全站设置中未保存的输入不会被后台刷新覆盖。
- 320、390、768 像素宽度验证五语言布局；手机导航始终可见，后台标签横向滚动，写作工具栏可换行。
