# 论坛与写作

首页现为开放论坛，所有正常登录的成员均可发表帖子。导航“新闻”保留编辑部内容，原新闻数据不变。精选区域采用轮播，支持前后切换、圆点定位、暂停和减少动画偏好。

## 权限

| 操作 | 游客 | 普通成员 | 子管理员 / 总管理员 |
| --- | --- | --- | --- |
| 阅读公开帖子与新闻 | 可以 | 可以 | 可以 |
| 发表帖子 | 需登录 | 可以 | 可以 |
| 发布新闻 | 不可以 | 不可以 | 可以 |
| 编辑、删除自己的帖子 | 不可以 | 可以；锁定或下架后不能编辑 | 可以 |
| 管理所有帖子、新闻 | 不可以 | 不可以 | 编辑、置顶、锁定、下架、恢复、删除 |
| 评论、点赞、私人收藏 | 需登录 | 可以 | 可以 |
| 编辑、删除评论 | 不可以 | 自己的评论；锁定后不能编辑 | 所有评论 |
| 用户角色、账号停用、全站设置、审计 | 不可以 | 不可以 | 仅总管理员 |

权限由 Supabase RLS、列级授权和触发器执行。作者、内容类型和身份字段不可通过客户端修改。停用账号不能发帖、编辑或互动。成员不能自行撤销管理员的锁定、下架或置顶操作。删除帖子会一并删除关联评论、点赞和收藏，因此界面要求确认。

## 写作流程

1. 首页选择“发表帖子”；管理员可在新闻页或管理中心选择“撰写新闻”。
2. 输入标题和正文。编辑器支持选中文字后格式化，以及标题、粗体、斜体、引用、列表、代码块、链接和图片。
3. 图片通过 HTTPS 地址插入，并可填写说明；当前不提供本地文件上传。阅读页仅渲染允许的格式，外部图片不发送来源页地址。
4. 草稿自动保存在当前浏览器，并按账号和内容隔离。点击“保存草稿”才会保存至服务器，之后可从“我的帖子”或管理中心继续编辑。成员自己的草稿不对其他成员或游客公开。
5. 使用五个语言标签编辑各语言版本；缺少翻译时读者看到原文和提示。已添加的语言版本需填写标题与正文。
6. 点击“预览”检查排版，再发布。原有纯文本新闻可直接进入新编辑器修改。

总管理员可在全站设置中关闭成员发帖或全站评论。普通成员每 30 秒最多新建一篇帖子，评论至少间隔 10 秒。帖子和新闻分别读取最近 500 条；后台每页 50 条。大规模全文检索、图片上传和预审队列仍需另行实现。

## 验证与维护

- `20261012113119_open_forum_and_rich_editor.sql` 是第三个迁移；已应用到现有项目，不要再次手工执行。
- `npm test` 在独立 PGlite 数据库验证迁移和跨角色权限，不修改生产数据。
- 接入 Supabase 公钥的本地构建可设置 `LIVE_SUPABASE=1` 运行浏览器测试。论坛发布和管理场景全部拦截后端请求，不会发布测试帖子或发送邮件。
- `npm run typecheck` 与 `npm run build` 检查类型及五语言静态页面。
- 线上安全检查保留一项原有认证提示：[泄露密码保护尚未启用](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection)。目前界面提供 OAuth 和邮箱一次性登录链接；此提示不涉及新增论坛权限。
