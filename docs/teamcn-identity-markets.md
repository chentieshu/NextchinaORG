# Teamcn：身份与钱包入口

品牌展示名为 Teamcn，前台 teamcn.org / www.teamcn.org，独立后台 tree.teamcn.org。保留既有服务资源名、数据库 RPC、登录存储键及历史 URL，避免品牌变更中断已有账户、资金或链接。

## 已实现

- 侧边栏无积分市场。钱包内提供余额、积分交易、预测市场三个入口；旧 `/market/` 跳转钱包内的交易页面。
- 文章保留五语言分类。帖子 category 在数据库写入时统一为 NULL，旧客户端传入的分类也不会保留；历史帖子已经清空该字段。
- 身份等级 1–60，默认依据成功入账的累计收到打赏。第 N 级门槛为 `100 × (N−1)²` 积分；1 级 0 分，60 级 348,100 分。管理端可以逐级编辑门槛，并切换收到、送出、两者合计。
- 头衔按 purchased + earned + held + codes + escrow 的持有积分计算，包含保留积分，排除商家担保押金。体验积分（如后续采用）不计入。
- 默认头衔：1,000 初有积蓄；5,000 小有盈余；10,000 积蓄有成；50,000 家底丰厚；100,000 富足之家；500,000 财力雄厚；1,000,000 百万富翁；5,000,000 富甲一方；10,000,000 千万巨富；20,000,000 富甲天下；**超过 100,000,000 富可敌国**。最小积分精度为 0.0001，故最后门槛存为 100,000,000.0001。
- 用户分别隐藏等级、头衔；公开 RPC 返回 NULL，不暴露累计打赏或真实余额。个人设置和总管理员授权接口可见完整信息。
- 总管理员可指定/取消等级与头衔覆盖值、冻结钱包、调整可用充值/收入积分及规则。调整要求近期邮箱验证、操作原因与幂等请求号，生成平衡账本分录；不修改既有流水、押金或托管资金。增加积分会增加平台应付责任。
- 批量读取公开身份，每批最多 100 人；按用户缓存一分钟。规则、身份配置与私有统计表不开放 REST 直接访问。

## 预测市场：当前边界

已提供钱包内的预测入口、BTC 五分钟默认市场定义、用户提案（规则/截止时间/来源）、总管理员审核与日志、分页及五语言界面。**尚未实现价格采集、订单撮合、投入扣款、轮次调度或收益结算。** `trading_enabled` 在服务器固定为 false；审核规则不会开启交易。

用户尚需确认：真实可兑付积分还是隔离的非兑付体验积分；双向奖池还是可买卖份额。机制确认后，再实现相应锁定、成交/份额、收益分配、失败退款和对账，不把奖池比例当成成交概率。

Polymarket 的订单簿和结算是两个不同子系统。官方涨跌市场使用 Chainlink TWAP；本项目当前没有接入该行情服务，不应借用其名称声称已实现同样结算。价格源、UTC 五分钟边界、持平判定、封盘时点、行情缺失与争议处理须在首单之前确定并保存版本。

参考：[Polymarket 价格与订单簿](https://docs.polymarket.com/concepts/prices-orderbook)、[结算规则](https://docs.polymarket.com/concepts/resolution)。运营主体此前声明位于新加坡；真实兑付积分预测功能上线前需由合适的专业人士确认适用许可与服务地区。[GRA 远程博彩说明](https://www.gra.gov.sg/harm-minimisation/unlawful-remote-gambling-activities)不等于针对本项目的法律认定。
